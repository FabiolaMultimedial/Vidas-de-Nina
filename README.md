# Las Mil Vidas de Nina

Juego publicado en GitHub Pages.

El código fuente y la configuración de Vite están en `codigo-fuente.zip`. Para editar: extraer, ejecutar `npm ci` y `npm run dev`. Para publicar cambios: `npm run build` y reemplazar los archivos web con los de `dist/`.

Los universos se guardan en este navegador. La música requiere conexión a Internet.
